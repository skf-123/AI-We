# 访问统计说明

> 一句话：Caddy 把访问日志写成 JSONL，Nuxt 只读日志尾部，`/admin/traffic` 用 Caddy Basic Auth 保护；不改数据库，不影响页面解析链路。

---

## 一、数据从哪来

Caddy 在反向代理之前记录每个请求，写入：

```text
/var/log/caddy/access.log
```

一条记录大致包含：

- `ts`：请求时间（Unix 秒）
- `request.remote_ip`：来源 IP
- `request.method` / `request.uri`：方法和路径
- `status`：HTTP 状态码
- `duration`：耗时（秒）
- `request.headers.User-Agent`：浏览器标识

不记录请求正文、代码内容或响应正文。

## 二、Caddy 配置

站点块里要有这段：

```caddyfile
log {
	output file /var/log/caddy/access.log {
		roll_size 50MiB
		roll_keep 4
		roll_keep_for 720h
	}
	format json
}
```

`50MiB × 4` 最多约 200 MB，`720h` 是 30 天。Caddy 自己轮转，不需要额外的 logrotate。

## 三、日志文件权限

Caddy 用 `caddy` 用户写，Nuxt 用 `aiweb` 用户读。目录用默认 ACL，轮转出来的新文件也会继承只读权限：

```bash
apt-get install -y acl
install -d -m 2750 -o caddy -g caddy /var/log/caddy
setfacl -m u:aiweb:r-x /var/log/caddy
setfacl -d -m u:aiweb:r-- /var/log/caddy
```

如果 `access.log` 已经存在，补一次：

```bash
chown caddy:caddy /var/log/caddy/access.log
chmod 640 /var/log/caddy/access.log
setfacl -m u:aiweb:r-- /var/log/caddy/access.log
```

不要 `chmod 644`：日志里有访客 IP，不需要让所有用户都能读。

## 四、管理员页面

页面：

```text
https://ai-web.work/admin/traffic
```

接口：

```text
GET /api/admin/traffic?hours=24&limit=500
```

两个地址都必须放在 Basic Auth 后面，不能只保护页面、忘了接口。

## 五、省略自己的访问

页面右上角有“已省略我们的访问 / 显示全部访问”开关，默认省略。省略规则：

- `TRAFFIC_OWN_IPS` 里列出的 IP（逗号分隔，写在服务器 `.env`）
- User-Agent 里带 `curl/` 或 `HeadlessChrome` 的探针请求

自己的出口 IP 变了以后，改 `.env` 里的 `TRAFFIC_OWN_IPS`，重启 `ai-web`，页面会按新 IP 省略。不要把外部扫描器加进这个列表，否则会看不到真实的外部探测。

## 六、Basic Auth

生成密码哈希（在服务器上跑）：

```bash
caddy hash-password --plaintext '你的密码'
```

把输出的 bcrypt 哈希放进**服务器上的** `/etc/caddy/Caddyfile`：

```caddyfile
@traffic path /admin/traffic* /api/admin/traffic*
basic_auth @traffic {
	admin <上一步输出的哈希>
}
```

然后：

```bash
caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile
systemctl reload caddy
```

密码哈希只放服务器，不提交仓库。改密码就是重新生成哈希、替换、reload。

## 七、仓库里的默认配置

`deploy/Caddyfile` 默认给访问统计路径返回 404：

```caddyfile
@traffic path /admin/traffic* /api/admin/traffic*
respond @traffic 404
```

这样新机器即使装了页面，也不会把 IP 直接暴露到公网。要启用时，把 `respond` 那行换成上面的 `basic_auth`。

## 八、页面怎么读日志

`server/api/admin/traffic.get.ts` 只读日志末尾最多 8 MB，不会把整个 200 MB 读进内存。

- 默认看最近 24 小时
- 可看最近 1 小时 / 7 天 / 30 天
- 最近请求最多返回 500 条
- 路径会去掉 `?` 后面的查询参数再展示
- IP、路径、状态码、耗时、User-Agent 都是只读展示
- 页面不提供删除日志的按钮

日志文件缺失时页面会提示“还没有访问日志”；权限不对时返回 503，并提示检查文件权限。

## 九、验证

不带密码：

```bash
curl -I https://ai-web.work/admin/traffic
# 401
```

带密码：

```bash
curl -I -u admin:你的密码 https://ai-web.work/admin/traffic
# 200
```

主站不受影响：

```bash
curl -I https://ai-web.work/
# 200
```

打开页面后能看到请求时间、IP、方法、路径和状态码；如果页面有记录但接口 401，先检查 Basic Auth 的 `path` 是否同时覆盖了 `/admin/traffic*` 和 `/api/admin/traffic*`。
